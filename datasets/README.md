# Dataset

Coloca aqui tu dataset en formato YOLO.

Estructura esperada:

```text
datasets/mi_dataset/
+-- images/
|   +-- train/
|   +-- val/
+-- labels/
    +-- train/
    +-- val/
```

No subas datasets demasiado grandes si GitHub no lo permite. Si pesa mucho, sube una muestra pequena y agrega en el README el enlace al dataset completo.
